# Lester & Winnie Bradford — memorial site

Read `spec.txt` first. It is the brief. In short: this is a public memorial website for the user's grandparents, **Lester Ezra Bradford** (forester and agriculturalist, d. 2019) and **Dr. Winifred "Winnie" Smith Bradford** (physician, 1922–2020). When the user types **"Continue"**, look over the live site, pick one or more self-contained improvements, build them, verify them, and publish them.

## Hard rules
- **Facts must come from public sources.** Every claim on the site needs a citation in `#sources` (use `<sup class="cite"><a href="#src-…">n</a></sup>`). Record new sources and facts in `research/notes.md` first. Never invent dates, names, quotes or anecdotes. Hedge anything uncertain ("very likely", "about"), and point out where sources disagree.
- **Media:** photos come from the public internet, credited in the caption (`.caption-meta`). Video comes only from the two family home movies in the repo root. They are gitignored because they are huge.
- **Don't identify people in the home movies.** We don't know who is who. Captions describe scenes only.
- **Privacy:** don't publish the user's email address or other personal contact details. Corrections go through GitHub issues. Don't publish details about living relatives (names, birth dates, addresses) even though the memoir contains them; say "five children".
- **Best sources:** Winnie's 210-page memoir *A Life Remembered* (a public Google Drive PDF) and Lester's *A Life in Tropical Agroforestry*. See `research/notes.md` for page numbers and for which photos have already been extracted.

## Layout
- `site/` holds the deployed static site. It has no framework and no build step. GitHub Pages serves it via `.github/workflows/pages.yml` on every push to `main`.
  - `index.html` is the single long-form page: hero, then chapters i–ix (Beginnings, Rotifunk, Three days, Reels, Skagit, Sudan & Pakistan, Map, Legacy, Timeline, Sources).
  - `css/style.css` contains design tokens in `:root`: paper / ink / laterite / canopy / palm.
  - `js/main.js` is progressive enhancement only. It handles reveals, the nav, video play-when-visible, the lightbox and the map chapters.
  - `media/reels/*.mp4|jpg` are muted H.264 clips (640px, CRF 27) with posters.
  - `media/photos/*-640.webp` (and `-1280` where the source is large enough) are generated by `tools/photos.py`.
  - `media/journey-map.svg` is generated by `tools/build-map.mjs`. Places and routes are defined in that file.
  - `media/og.jpg` is the social card, generated by `tools/og.py`.
- `assets-src/photos/` holds the original downloaded photos. Add new images here, then run `python3 tools/photos.py`.
- `tools/` holds the build helpers. Run `npm install` there once.
  - `node tools/build-map.mjs`
  - `python3 tools/photos.py`
  - `python3 tools/og.py`
  - `python3 tools/dims.py` (writes width/height on every `<img>` — run after adding images)
  - `node tools/shot.mjs http://localhost:8765/ <outdir>` takes full-page desktop and mobile screenshots and reports console, network and 4xx errors.
- `research/notes.md` is the running research log: verified facts, sources, open questions and dead ends.

## Making video clips
The source files are `Panama 1955 & Bradford home movies.m4v.mp4` and `Fitzgerald Bradford home movies.m4v.mp4`.
- In the first file, the Panama portion (0:00–~15:15) is **not** Lester and Winnie. They were in Sierra Leone in 1955. The Bradford portion runs from ~15:15 to the end. At 24:37–25:31 there is a send-off aboard the Farrell Lines ship *African Dawn*.
- The Fitzgerald file is 1970s family footage (canoe trips, gatherings).
- Encode recipe (see `git log` for exact flags): `ffmpeg -ss A -to B -i SRC -an -vf "crop=iw*0.96:ih*0.96,scale=640:-2,hqdn3d=1.5:1.5:4:4,eq=saturation=1.08:contrast=1.03" -c:v libx264 -preset slow -crf 27 -pix_fmt yuv420p -movflags +faststart out.mp4`

## Verify before publishing
1. `cd site && python3 -m http.server 8765`, then run `node tools/shot.mjs` and look at the screenshots at desktop and mobile widths.
2. The page must have no console errors and no 404s. The CSP in `<meta http-equiv>` forbids inline styles and scripts and all third-party origins. Keep it that way: add CSS classes instead of `style=""`.
3. Respect `prefers-reduced-motion`. Make sure the page still reads without JS.
4. Commit and push to `main`, then confirm the Pages deploy succeeded with `gh run list`. The live URL is https://lukebradford.github.io/lesterandwinnie/
